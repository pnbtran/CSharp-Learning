# 022 CLASS STUDENT ĐỂ TÍNH GPA

## Tóm tắt
- Thực hành viết `class student` và nhiều `constructor` (mặc định, có tham số).

- Viết phương thức cho object tự tính GPA + thêm phương thức xếp loại GPA.

- Quảng lí nhiều sinh viên bằng mảng đối tượng.

## Thuật toán
- Cấu trúc chương trình
```txt
Program
│
├── Student (Class)
│   ├── Properties
│   ├── Constructors
│   ├── Calculate + Rank
│   └── Find Max
│
└── Main()
    ├── Tạo dữ liệu
    ├── Quản lý danh sách
    ├── Gọi xử lý
    └── Xuất kết quả
```

## Lưu ý
- cú pháp `{CalculateGPA():F2}` nghĩa là in GPA làm tròn 2 chữ số thập phân (F2 = fixed-point, 2 số lẻ).
